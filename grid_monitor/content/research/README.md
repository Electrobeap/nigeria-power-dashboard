# Research records

This directory intentionally contains no seeded publications.

Add an author-approved JSON record named after its unique slug. Store its
searchable PDF under papers/. Both are reviewed in Git before publication.
Drafts are excluded from public routes; this directory is not Flask static
storage. A public Git repository is not suitable for confidential drafts.

See docs/research-publishing.md and docs/research-record.template.json.
